# 课程实验报告流水线检查清单

## 输入检查

- 原始实验题目是否存在。
- 当前 Word 报告或参考模板是否存在。
- 输入数据、图片、音频、CSV、代码是否存在。

## 阶段产物

- `school-lab-report` 产物：每题基础 Markdown。
- `school-lab-md-expander` 产物：每题通过质量检查的过程 Markdown；原稿已足够时可直接使用原稿，内容不足时才在 `expanded/` 下生成补写版。
- `school-lab-data-analysis` 产物：`analysis/` 下数据处理分析 Markdown。
- `school-lab-method-conclusion` 产物：`summary/` 下方法步骤与实验结论 Markdown。
- `school-lab-docx-report` 产物：最终 DOCX。
- 对公式较多的算法、模型结构、变换、指标或优化目标，过程 Markdown 必须包含推导链、符号解释和结合题目的例子，不能只列核心公式；若原稿已经做到这一点，不要再重写一份详细版。
- 已有正确公式必须保持原样。补写时只增加缺失解释或推导，不得无故重打公式、替换符号、合并公式或把 LaTeX 改成普通文字。
- `analysis/` 产物必须保留模板式结果结构：`结果文件`、`实验结果展示`、`结果数据表`、`结果分析`。只有实际结果与理论/预期结果差距明显、指标较差、输出异常或结果不稳定时，才单独写 `误差来源与改进`。
- 每道有真实结果证据的题目，`结果分析` 至少应有两到三段实质分析，不能只有图注、表格说明或一句“结果较好”。
- 已准备好的 Markdown 迁入 Word 时不得被摘要化；DOCX 阶段只能排版和转换，不能缩减 `expanded/`、`analysis/`、`summary/` 的正文。

## DOCX 质量检查

- 模板固定区域未被改动。
- 正文、代码、图注、表格符合格式要求。
- Word 各章节与源 Markdown 对照后无明显缩短，尤其是 `数据处理分析` 不得只剩图片和短说明。
- 公式是可视化公式，不是原始 LaTeX。
- 图片不变形。
- 表格整体居中，不是仅单元格文字居中。
- 表格不溢出。
- 代码不裁剪。
- 渲染页面无重叠、乱码、缺字、异常空白。

## 分区检查

- 过程 Markdown 只包含题目要求、知识点、原理公式、算法流程、代码设计和代码文本。
- 过程 Markdown 的 `实验原理` 对公式密集内容应包含定义/假设、中间推导、最终公式、变量说明、题目例子和代码对应关系。
- 过程 Markdown 不应包含结果图片、结果表格、运行指标表、图注、表注或针对实际输出效果的结果分析。
- `analysis/` 下的数据处理分析文件应集中包含结果图片、结果表格、CSV 指标、运行日志摘要和结果解释。
- Word 迁入前必须再次过滤 `实验过程及内容` 源 Markdown，移出标题含 `实验结果`、`结果展示`、`结果分析`、`数据处理分析`、`输出结果`、`运行结果` 的小节。
- 从 `实验过程及内容` 移出的结果内容必须完整进入 `数据处理分析`，不得因为分区过滤而丢失。
- `数据处理分析` 迁入 Word 后应与 `analysis/*.md` 对照：结果文件、结果展示、结果数据表、结果分析段落不能少。

## 参考格式检查

- 若用户提供 `Lab1.docx` 或其他满意报告，先解析参考报告同名区域的表格单元格、段落样式、行距、编号、公式和代码样式。
- 最终 DOCX 的 `实验过程及内容` 必须视觉上匹配参考报告，不得改成通用 Markdown 标题样式。
- 若参考报告中过程区在表格单元格内，目标报告也应在原模板对应单元格内写入，不要额外创建新框或新区域。

## 表格检查

- 普通报告表格应为整体居中三线表；短表格按内容宽度自适应，左右留白基本均衡。
- “表格居中”指 Word 表格对象居中，例如 `table.alignment = WD_TABLE_ALIGNMENT.CENTER` 或 `<w:tblPr><w:jc w:val="center"/>`，不是只设置单元格段落居中。
- 渲染检查时，如果表格贴左、左右留白明显不均，或者只是单元格文字居中，判定为失败并修复。

## 公式检查

- 公式是可视化公式，不是原始 LaTeX。
- 行内公式和带上下标变量也是可视化公式。
- 正文区域没有残留 `$$`、`\frac`、`\sqrt`、`\sum`、`_{`、`^{` 等原始公式标记，代码块除外。
- 不允许把 LaTeX 简化成普通字符串后塞进 `m:oMath`；必须使用 MathML 到 OMML 或结构化 OMML。

## 题目锚点检查

- `实验过程及内容` 中原模板已有的题目编号和题干必须完整保留，例如 `1.1`、`2.1`、`2.2`、`3.3`。
- Word 迁入时只在题目下面追加内容，不删除、不改写、不重新编号题目。
- 概念题在题目下面直接回答，不添加 `题目分析`、`实验原理`、`实验设计`、`核心代码`、`代码说明`、`本题小结`。
- 编程题在题目下面使用无编号加粗小标题：`题目分析`、`实验原理`、`实验设计`、`核心代码`、`代码说明`。
- 过程区最终不得出现旧结构标题：`题目要求`、`涉及知识点`、`算法流程`、`代码设计与关键代码`、`实验材料与运行方式`、`本题结果和过程解释`、`本题小结`。
