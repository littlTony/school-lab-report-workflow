# School Lab Methods and Conclusion Writer

## Purpose

Use this skill near the end of the lab-report workflow. It produces two standalone sections:

1. `方法、步骤`
2. `实验结论` or `实验总结`

It should consume the per-task expanded Markdown and data-analysis outputs, then summarize the whole experiment without redoing long formula derivations.

## Inputs

Use:

- Original assignment requirements.
- Markdown generated by `school-lab-report`.
- Expanded Markdown from `school-lab-md-expander`.
- Data-analysis Markdown from `school-lab-data-analysis`.
- Code/result paths and high-level outcomes.

## Output Location

Create a standalone Markdown file such as:

```text
summary/Lab1_方法步骤与实验结论.md
```

## `方法、步骤` Rules

This section is a concise design summary, not a theory section.

Write by task group:

```markdown
## 方法、步骤

一、概念题
1. ...
2. ...

二、编程题
1. ...
2. ...
```

Each point should describe what was done:

- Read/understand the question.
- Establish mathematical model or algorithm route.
- Process data/image/signal.
- Run code or calculate values.
- Save results and analyze them.

Do not include long derivations; those belong to `实验过程及内容`.

## `实验结论` Rules

This section must use first-person completed tense.

Use phrasing like:

```text
通过本次实验，我完成了...
我掌握了...
我实现了...
我分析了...
我发现...
```

Avoid second-person wording.

The conclusion should summarize:

- What experiments I completed.
- What theories or algorithms I understood.
- What code/results I obtained.
- What limitations or improvements I recognized.

## Numbering Rules

Use this hierarchy:

1. `一、`
2. `1.`
3. `(1)`
4. `1)`
5. `a.`

Keep numbering consistent with the Word report template.
