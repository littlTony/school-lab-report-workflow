# School Lab Methods and Conclusion Writer

## Purpose

Use this skill near the end of the lab-report workflow. It produces or validates two standalone sections:

1. `方法、步骤`
2. `实验结论` or `实验总结`

It should consume the per-task process Markdown and data-analysis outputs, then summarize the whole experiment without redoing long formula derivations.

Do not assume a new `详细版` is needed. If an existing `方法步骤与实验结论.md` is already concise, complete, and aligned with the report template, use it as the authoritative source. The `方法、步骤` section is intentionally brief in most lab reports; making it longer often makes the report worse.

## Inputs

Use:

- Original assignment requirements.
- Markdown generated by `school-lab-report`.
- Checked process Markdown from `school-lab-md-expander`; this may be the original Markdown if it already passed quality checks.
- Data-analysis Markdown from `school-lab-data-analysis`.
- Code/result paths and high-level outcomes.
- Existing `summary/*.md` files when present.

## Output Location

Create a standalone Markdown file such as:

```text
summary/Lab1_方法步骤与实验结论.md
```

Do not automatically create `*_详细版.md`. If the existing summary file is sufficient, keep it unchanged. If it is missing a required point, update or create a minimal `*_补充.md` only when needed.

## `方法、步骤` Rules

This section is a concise design summary, not a theory section.

Default to concise. Do not expand this section just to make it look longer. It should not contain detailed formulas, long derivations, large code explanations, or result-table discussions.

Write by task group:

```markdown
## 方法、步骤

一、概念题
1. ...
2. ...

二、编程题
1. ...
2. ...
```

Each point should describe what was done:

- Read/understand the question.
- Establish mathematical model or algorithm route.
- Process data/image/signal.
- Run code or calculate values.
- Save results and analyze them.

Do not include long derivations; those belong to `实验过程及内容`.
Do not create a more detailed version when the original method steps already cover the actual workflow.

## `实验结论` Rules

This section must use first-person completed tense.

Use phrasing like:

```text
通过本次实验，我完成了...
我掌握了...
我实现了...
我分析了...
我发现...
```

Avoid second-person wording.

The conclusion should summarize:

- What experiments I completed.
- What theories or algorithms I understood.
- What code/results I obtained.
- What limitations or improvements I recognized.

If an existing conclusion already covers these points in first person, preserve it. Only add missing completion facts or correct obvious omissions.

## Numbering Rules

Use this hierarchy:

1. `一、`
2. `1.`
3. `(1)`
4. `1)`
5. `a.`

Keep numbering consistent with the Word report template.
